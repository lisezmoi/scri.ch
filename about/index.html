scri.ch is a hackable
drawing tool.

How to use

  1. Go to scri.ch
  2. Draw
  3. Save
  4. Share the URL

Tips

  • Change colors or define a fixed size using URL params
  • Don't look for the eraser tool
  • Continue an existent drawing and save your version
  • Refresh the page [F5] to clear your drawing
  • Turn your scrich into an image by adding “.png” to the URL
  • Zoom an image by adding “-2x.png” to the URL
